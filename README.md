# 🔎 CampusFind

A simple Flask + SQLite campus Lost & Found application.

## Features

- 🔐 Student login
- 🔴 Report lost items
- 🟢 Report found items
- 🔎 Search and filter reports
- 📍 Store item location
- 📅 Store report date
- 📞 Contact information
- 📄 View item details
- ✓ Mark your own report as resolved
- 🗑️ Delete your own report
- ⚠️ Input validation and error handling
- 📱 Mobile-friendly UI
- 💾 SQLite database

## Primary User Flow

```text
Open App → Search / Filter → View Details → Contact Owner / Finder
```

## Run

```bash
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`

## Demo Login

`student` / `student123`

## Technology

Python, Flask, SQLite, HTML, CSS, JavaScript, Jinja2, Werkzeug
